# MARS STORE

Starter sklepu MARS STORE (Next.js + Supabase), przygotowany do dalszej konfiguracji.

## Ważne
- Nie wpisuj klucza `service_role` do kodu przeglądarki.
- Nie publikuj haseł ani tokenu Telegrama.
- Przed uruchomieniem produkcyjnym należy dodać bezpieczne logowanie administratora, walidację zamówień i integrację dostaw/płatności.

## Uruchomienie lokalne
1. Zainstaluj Node.js LTS.
2. Skopiuj `.env.example` do `.env.local`.
3. Uzupełnij zmienne środowiskowe.
4. Uruchom `npm install`, potem `npm run dev`.
